                                   B    Formal Description of The Running Example
The sequence task of the running example (Example 1) is formalised by the following Temporal Datalog program—for Tempo-
ral Datalog see (Ronca et al. 2022). Let wood , iron, fire, steel , and factory be unary unary predicates. They are used to model
the input. For example, wood (17) is in the input trace if the agent collects wood at time 17, and factory(5) is in the input trace
if the agent attempts to use the factory at time 5. Additionally, let getWood , getIron, getFire, getSteel , and useFactory be
unary predicates. They are defined by the following rules.
                                                                                wood (t) → getWood (t)                          (4)
                                                                            getWood (t) → getWood (t + 1)                       (5)
                                                                                 iron(t) → getIron(t)                           (6)
                                                                              getIron(t) → getIron(t + 1)                       (7)
                                                                                  fire(t) → getFire(t)                          (8)
                                                                              getFire(t) → getFire(t + 1)                       (9)
                                                                                 steel (t) → getSteel (t)                      (10)
                                                                             getSteel (t) → getSteel (t + 1)                   (11)
                                                          getSteel (t − 1) ∧ factory(t) → useFactory(t)                        (12)
                   getWood (t − 1) ∧ getIron(t − 1) ∧ getFire(t − 1) ∧ factory(t) → useFactory(t)                              (13)
                                                                          useFactory(t) → useFactory(t + 1)                    (14)
Then, at any given time point τ , the task has been completed if useFactory(τ ) is entailed by the input facts and the rules above.
